# UI/UX Design Pro: Apple HIG & Enterprise Data Interface Standards

## Core Principles
1. **Light Mode First**: Always prefer Light Mode by default (`#f5f5f7` canvas, `#ffffff` elevation, `#1d1d1f` primary typography).
2. **Zero AI Slop**: Reject pulsing radar circles, rainbow gradients, marketing eyebrows, generic slogans, and oversized bubbly metric boxes.
3. **Typography IS Design**: SF Pro text hierarchy, SF Mono for technical identifiers, tabular figures for numbers and timestamps.
4. **Subtle Layering**: Surface elevation through hairline borders (`#e5e5ea`, `#f2f2f7`) and subtle ambient shadows rather than harsh contrast.
5. **The Table is the Hero**: For auditing and monitoring dashboards, tabular data must be immediately accessible above the fold without unnecessary vertical clutter.
